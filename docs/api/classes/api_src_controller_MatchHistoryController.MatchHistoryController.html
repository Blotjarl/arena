    Class MatchHistoryController

    GET /players/:id/matches?page=&pageSize= — serves a player's paginated match history (R7.3).

    Uses the default (untyped) AbstractController generics via the shared NULL_MODEL/NULL_VIEW stand-in — see 10_api_1's design note 4 for why: no domain Model this REST controller observes, and MatchHistoryResponseView is a plain formatter, not a push-based View.

    • getHistory(req: Request, res: Response): Promise<void>

      Fetches a page of match history via MatchRepository.findHistoryForPlayer and formats it through MatchHistoryResponseView.
